# SIPL Language Toolkit

Інструментарій для навчальної імперативної мови програмування **SIPL (Simple Imperative Programming Language)** у межах проєкту з дисципліни «Теорія програмування».

## Обрані модулі проєкту

| Код | Модуль | Бали | Статус |
| :--- | :--- | :---: | :---: |
| `CORE-01` | Формальна специфікація SIPL (БНФ/EBNF, граматика Lark, позитивні та негативні тести) | 0.5 | Заплановано |
| `CORE-02` | Парсер SIPL та типізоване AST із прив'язкою до позицій у коді (`SourceSpan`) | 1.5 | Заплановано |
| `CORE-03` | Інтерпретатор SIPL із моделлю стану та контролем нескінченних циклів | 2.0 | Заплановано |
| `CORE-04` | Подієва модель виконання та структуроване трасування (`trace`) | 1.0 | Заплановано |
| `CORE-05` | Інтерфейс командного рядка (CLI: `parse`, `check`, `run`, `trace`, `sem`) | 1.0 | Заплановано |
| `CORE-06` | Еталонний набір сумісності (Conformance Suite) для SIPL | 1.0 | Заплановано |
| `SEM-01` | Автоматична побудова семантичного терма SIPL у композиційній нотації курсу | 2.0 | Заплановано |
| `SEM-02` | Покрокове обчислення семантичного терма на заданому стані з поясненням правил переходу | 2.0 | Заплановано |

## Архітектура репозиторію

```text
SIPL/
├── grammar/          # Формальна машиночитана граматика SIPL (sipl.lark)
├── src/sipl/         # Вихідний код пакету sipl
│   ├── __init__.py
│   ├── ast.py        # Типізоване дерево абстрактного синтаксису та SourceSpan
│   ├── parser.py     # Синтаксичний аналізатор та діагностика помилок
│   ├── interpreter/  # Виконання програм, стан змінних, події та трасування
│   ├── semantics/    # Побудова та покрокове обчислення семантичних термів
│   └── cli.py        # Інтерфейс командного рядка (CLI)
├── examples/         # Приклади програм мовою SIPL
├── tests/            # Модульні, інтеграційні та еталонні (conformance) тести
└── docs/             # Специфікація мови, граматики та семантики
```

## Підтримуваний синтаксис SIPL та задокументовані розширення

Базова граматика відповідає канонічному визначенню мови SIPL (М.С. Нікітченко, «Теорія програмування»; О.В. Шишацька та ін., «Теорія програмування. Практикум»). Додатково підтримуються консервативні синтаксичні розширення:
- `!` — префіксне логічне заперечення (еквівалент канонічного `¬`);
- `||` — інфіксна логічна диз'юнкція (еквівалент канонічного `∨`);
- `/` — інфіксне цілочисельне ділення (аналог `div` із практикуму).
