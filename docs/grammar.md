# Формальна специфікація граматики мови SIPL (`CORE-01`)

Цей документ описує формальну синтаксичну та лексичну специфікацію навчальної імперативної мови програмування **SIPL (Simple Imperative Programming Language)**, реалізовану у машиночитаному файлі граматики [`grammar/sipl.lark`](../grammar/sipl.lark).

Специфікація узгоджена з базовими навчальними матеріалами курсу:
1. М.С. Нікітченко. *«Теорія програмування»*, 2010/2020 (Розділ 1.2, Таблиці 1.2, 1.4, с. 8–10).
2. О.В. Шишацька, А.В. Криволап, А.В. Шишацький. *«Теорія програмування. Практикум»*, 2024 (Тема 1, Таблиці 1.1–1.2, с. 5–7).

## 1. Канонічна БНФ мови SIPL

У таблиці нижче наведено канонічні правила Бекуса-Наура (БНФ) для базової мови SIPL із позначеннями правил за підручником та практикумом:

| Категорія | Код правила | Правило БНФ | Короткий опис |
| :--- | :---: | :--- | :--- |
| **Програма (`P`)** | $NP_1$ ($P_1$) | `<програма> ::= begin <оператор> end` | Програма як головний блок |
| **Оператор (`S`)** | $NS_1$ ($S_1$) | `<оператор> ::= <змінна> := <вираз>` | Оператор присвоювання |
| | $NS_2$ ($S_2$) | `<оператор> ::= <оператор> ; <оператор>` | Послідовна композиція операторів |
| | $NS_3$ ($S_3$) | `<оператор> ::= if <умова> then <оператор> else <оператор>` | Умовний оператор (розгалуження) |
| | $NS_4$ ($S_4$) | `<оператор> ::= while <умова> do <оператор>` | Циклічний оператор із передумовою |
| | $NS_5$ ($S_5$) | `<оператор> ::= begin <оператор> end` | Складений оператор (блок) |
| | $NS_6$ ($S_6$) | `<оператор> ::= skip` | Порожній оператор |
| **Вираз (`a`)** | $NA_1$ ($A_1$) | `<вираз> ::= <число>` | Цілочисельна константа |
| | $NA_2$ ($A_2$) | `<вираз> ::= <змінна>` | Ім'я змінної |
| | $NA_3$ ($A_3$) | `<вираз> ::= <вираз> + <вираз>` | Додавання |
| | $NA_4$ ($A_4$) | `<вираз> ::= <вираз> - <вираз>` | Віднімання |
| | $NA_5$ ($A_5$) | `<вираз> ::= <вираз> * <вираз>` | Множення |
| | $NA_6$ ($A_6$) | `<вираз> ::= ( <вираз> )` | Дужковий арифметичний вираз |
| **Умова (`b`)** | $NB_1$ ($B_1$) | `<умова> ::= <вираз> = <вираз>` | Перевірка на рівність |
| | $NB_2$ ($B_2$) | `<умова> ::= <вираз> > <вираз>` | Перевірка «більше» |
| | $NB_3$ ($B_3$) | `<умова> ::= <умова> ∨ <умова>` | Логічна диз'юнкція («або») |
| | $NB_4$ ($B_4$) | `<умова> ::= ¬ <умова>` | Логічне заперечення («не») |
| | $NB_5$ ($B_5$) | `<умова> ::= ( <умова> )` | Дужковий логічний вираз |
| **Змінна (`x`)** | $NV_i$ ($V_i$) | `<змінна> ::= M \| N \| S \| I \| R \| Q \| ...` | Ідентифікатор змінної |
| **Число (`n`)** | $NN_i$ ($N_i$) | `<число> ::= ... \| -1 \| 0 \| 1 \| 2 \| 3 \| ...` | Ціле число зі знаком або без |

## 2. Задокументовані консервативні розширення відносно базового SIPL

Відповідно до вимог проєкту (`CORE-01`), реалізація підтримує три консервативні розширення синтаксису, які явно виділені у граматиці та документації:

| Розширення | Категорія | Канонічний відповідник / зміст | Правило граматики | Семантичний базовий елемент ($\mathcal{A}_{SIPL}$) |
| :---: | :--- | :--- | :--- | :--- |
| **`!`** | Логічний оператор (унарний префіксний) | ASCII-синонім канонічного оператора заперечення `¬` | `<умова> ::= ! <умова>` (`NB4_ext`) | $S^1(neg, sem\langle b \rangle)$ |
| **`\|\|`** | Логічний оператор (бінарний інфіксний) | ASCII-синонім канонічного оператора диз'юнкції `∨` | `<умова> ::= <умова> \|\| <умова>` (`NB3_ext`) | $S^2(or, sem\langle b_1 \rangle, sem\langle b_2 \rangle)$ |
| **`/`** | Арифметичний оператор (бінарний інфіксний) | Цілочисельне ділення (аналог `div` із практикуму та консервативного розширення $SIPL_C$) | `<вираз> ::= <вираз> / <вираз>` (`NA_div`) | $S^2(div, sem\langle a_1 \rangle, sem\langle a_2 \rangle)$ |

> **Примітка щодо семантики цілочисельного ділення `/` (`div`):**
> Для цілих чисел $v_1, v_2 \in \mathbb{Z}$ операція `/` виконує цілочисельне ділення з відсіканням дробової частини до нуля (`int(v1 / v2)` у Python, що збігається з математичним цілочисельним діленням для невід'ємних чисел у прикладах курсу). При $v_2 = 0$ значення є невизначеним ($\bot$), а інтерпретатор генерує спеціалізовану помилку виконання `DivisionByZeroError`.

## 3. Пріоритети та асоціативність операцій

Для усунення неоднозначності при побудові дерева розбору в [`grammar/sipl.lark`](../grammar/sipl.lark) реалізовано ієрархію нетерміналів згідно з правилами пріоритетів підручника (с. 10). Усі бінарні операції є **лівоасоціативними**.

| Рівень пріоритету (1 — найвищий) | Оператори / Конструкції | Тип та асоціативність | Нетермінал у `sipl.lark` |
| :---: | :--- | :--- | :--- |
| **0 (первинні)** | `<число>`, `<змінна>`, `(<вираз>)`, `(<умова>)`, `begin ... end`, `skip` | Атомарні конструкції / дужки | `expr_atom`, `cond_atom`, `single_stmt` |
| **1** | `*`, `/` | Бінарні арифметичні, лівоасоціативні | `expr_term` |
| **2** | `+`, `-` | Бінарні арифметичні, лівоасоціативні | `expr` |
| **3** | `=`, `>` | Бінарні операції порівняння (між двома `<вираз>`) | `cond_atom` |
| **4** | `¬`, `!` | Унарне префіксне логічне заперечення (правоасоціативне вкладення) | `cond_neg` |
| **5** | `∨`, `\|\|` | Бінарна логічна диз'юнкція, лівоасоціативна | `cond` |
| **6** | `:=` | Оператор присвоювання (`<змінна> := <вираз>`) | `single_stmt` (`assign_stmt`) |
| **7** | `while <умова> do <оператор>` | Циклічний оператор | `single_stmt` (`while_stmt`) |
| **8** | `if <умова> then <оператор> else <оператор>` | Умовний оператор | `single_stmt` (`if_stmt`) |
| **9 (найнижчий)** | `;` | Послідовна композиція операторів, лівоасоціативна | `stmt` (`seq_stmt`) |

## 4. Лексична специфікація

1. **Ключові слова (зарезервовані, чутливі до регістру):**
   - `begin`, `end`, `if`, `then`, `else`, `while`, `do`, `skip`.
   - Ключові слова не можуть використовуватися як імена змінних (`IDENT`).
2. **Ідентифікатори змінних (`IDENT`):**
   - Регулярний вираз: `/(?!(?:begin|end|if|then|else|while|do|skip)\b)[A-Za-z_][A-Za-z0-9_]*/`.
   - Починаються з латинської літери (`A–Z`, `a–z`) або підкреслення (`_`), після чого можуть слідувати літери, цифри або підкреслення.
   - Приклади з курсу: `M`, `N`, `S`, `I`, `R`, `Q`, `x`, `y`, `x1`.
3. **Цілі константи (`NUMBER` та від'ємні літерали):**
   - Невід'ємні цілі константи задаються регулярним виразом `/0|[1-9][0-9]*/` (без ведучих нулів на кшталт `01`).
   - Від'ємні цілі константи (`-1`, `-2`, ...) розпізнаються правилом `neg_number_expr` (`"-" NUMBER`) у первинній позиції виразу (`expr_atom`), що дозволяє одночасно підтримувати канонічні від'ємні числа з Таблиці 1.2 (`X := -1`) і коректно розбирати бінарне віднімання без пробілів (`M-1` як `M - 1`).
4. **Оператори та роздільники:**
   - Арифметичні: `+`, `-`, `*`, `/`
   - Порівняння: `=`, `>`
   - Логічні: `¬`, `!`, `∨`, `||`
   - Присвоювання: `:=`
   - Роздільник послідовності операторів: `;`
   - Групувальні дужки: `(`, `)`
5. **Пробільні символи (`WS`):**
   - Пробіли (`' '`), табуляції (`'\t'`), переводи рядків (`'\n'`, `'\r'`) ігноруються між токенами (`%ignore WS`).
6. **Коментарі:**
   - Базова граматика SIPL не передбачає коментарів у вихідному коді програм.
